# Polaris PDA / 微信小程序发布说明

`main-app/` 是可直接部署到 HTTPS 域名的 H5 + Vue 3 现场作业端，浏览器或 H5+ 容器可调用后置摄像头。摄像头优先使用原生 `BarcodeDetector`，不支持时提供人工编码输入，便于在企业微信、微信 WebView 或 PDA 浏览器中兜底。

当前 PDA 已覆盖参考 `even-pda` 的现场主流程：收料入库、生产领料、生产退料、合格上架、调拨移库、扫码盘点、成品入库、销售出库、报废出库、库存调整、现场报工、来料检验和条码追溯。来料检验采用“扫描物料/批次 → 自动匹配检验计划 → 录入多项结果 → 自动判定”的方式；普通库存作业仍采用“扫码识别 → 确认数量/库位 → 提交”的方式。网络中断时，已确认的库存提交会暂存到当前租户的本地补传队列，恢复网络后自动重试。

## 微信小程序能力

`miniprogram/` 是最小微信小程序壳，通过 `web-view` 打开 H5。发布前请：

1. 将 `pages/index/index.wxml` 中的 H5 URL 替换为已备案的 HTTPS 域名。
2. 在微信公众平台配置业务域名，并将真实 `appid` 写入 `project.config.json`。
3. 用微信开发者工具打开 `main-app/miniprogram/`，预览、真机调试并提交审核。

## 生产注意事项

- 摄像头调用必须在 HTTPS 或 localhost 环境下进行，并向用户解释权限用途。
- `BarcodeDetector` 在不同设备覆盖不一致，生产可通过企业统一浏览器或补充 ZXing/微信扫一扫能力增强识别率。
- 现场提交接口需要启用真实登录令牌；库存事务已使用 `idempotencyKey` 防止离线补传或网络重试造成重复过账，报工/盘点仍应由服务端按业务单据增加幂等约束。
